# 🧮 Calculator Application

## 📖 Overview

The **Calculator Application** is a full-stack web application designed to perform basic mathematical operations through an interactive and colourful user interface. It provides a simple and efficient way for users to perform calculations with an attractive GUI.

The project is developed using **HTML, CSS, and JavaScript** for the frontend and **Node.js with Express.js** for the backend. The application demonstrates frontend design, backend integration, and full-stack development concepts.

---

## 🚀 Features

* Perform basic arithmetic operations
* Colourful and interactive user interface
* Responsive calculator design
* User-friendly button controls
* Real-time calculation results
* Frontend and backend integration
* Simple and efficient functionality

## ▶️ How to Run

### Step 1: Clone the Repository

```bash
git clone https://github.com/Siddukrishna-15/calculator-application.git
```

### Step 2: Navigate to Backend Folder

```bash
cd Backend
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Server

```bash
node server.js
```

### Step 5: Run Frontend

Open the `index.html` file in your browser to use the calculator application.
